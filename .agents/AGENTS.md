## Guidelines

Be extremely concise in your responses. Always answer in ASD-STE100 Simplified Technical English.
Do not create commits or push code unless explicitly asked to do so.

## Coding style

Comments should be 1-2 lines maximum and should only be used when the code is not self-explanatory. Do not update READMEs unless explicitly asked to do so.
Always use descriptive variable names, unless the variable is a common loop index (e.g., `i`, `j`, `k`), in an iterator, a Go `WaitGroup`...
